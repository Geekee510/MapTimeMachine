## 四、几个数据设计上的判断（值得你先看）

1. **"名义 / 实际"必须分开标**。1940 年的江苏：名义属汪伪、城镇由日军占、乡村部分由新四军控制。
   数据里用 `seg.note` 标注 `名义` / `实际` / `游击`，渲染时以透明度区分——这是近代史地图最有信息量的地方，
   合并成一块色就全废了。
2. **军阀控制区不是行政区**，是驻防范围。所以只到省粒度 + note，细节交给战争动画的行军路线补。
3. **口岸分三类**（约开 40 / 自开 30 / 租借），不是同一性质，地图上要用不同符号。
4. **势力范围不是领土**：只有俄在满洲、德在山东是"租借地 + 铁路"的实控；英国"长江流域"只是
   1898 年照会里的"不割让"承诺，note 里已写明，别画成和满洲一样的实心色块。
5. **三支红四军**：井冈山（→红一方面军）、湘鄂西（→红二方面军）、鄂豫皖（→红四方面军），
   番号相同、互不相干。数据已按三个独立 id 建，报告里也单列了。

## 五、时间编码（重要，别再踩）

全库统一 `年.月`，月份两位：`1937.07` = 1937 年 7 月。比较用 `tkey()`，显示用 `timeLabel()`。

**踩过的坑**：早期一半数据按"小数年"写（`0.5` = 年中），一半按"年.月"写（`.7` = 7 月），
混在一起后 `1937.10` 被当成 1 月、`start > end` 报错 337 处。现已全部规范为两位月份，
体检脚本会拦截不合规写法。

## 七、下一步接入渲染的顺序建议

1. **疆域层**（最容易验证）：`factionsAtYear(year)` → 省名解析 → dissolve → 填色 + 轮廓。可直接复刻古代史 `territoryGen`。
2. **事件图钉**：`eventsAtYear(year)` → DOM Marker（复用 `pinLayer`），点击弹 `article` 卡片。
3. **战争回放**：`MODERN_WARS` 已是 `chinaHist/wars.js` 同构 schema，`activeWars` / `warView` 可直接复用。
4. **专项图层**：口岸点 → 租界点 → 铁路线（Chaikin 平滑）→ 势力范围面（半透明 + 斜纹）。
5. **文字**：`stageAtYear(year)` 驱动侧栏；`TOPICS` 进专题页。
6. **时间轴**：1840–1949，默认 1900 或 1937。
