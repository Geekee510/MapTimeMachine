# 中国工农红军编制沿革研究报告（1927—1937）

> **用途**：为「中国近代史」地图（第四幅图）建立红军编制数据底座，同时作为「军阀大战 / 红军长征 / 抗日战争」三个专题的叙事骨架。
> **口径**：以**部队番号**为单位，逐条追踪「何时成立 → 由哪些部队合并而来 → 主官是谁 → 兵力多少 → 又合并/改编成了什么」。
> **结论先行**：整个红军史可以压缩成一句话——**三支"红四军"长出三大方面军，三大方面军加陕北红军改编成八路军三个师，南方游击队改编成新四军。**

## 二、五个阶段（地图时间轴建议按此分段）

| 阶段 | 时间 | 一句话特征 | 编制关键变化 |
|---|---|---|---|
| **一、创建** | 1927.8—1930.5 | 从起义武装到"红军"定名 | 工农革命军 → 红军；井冈山红四军成立 |
| **二、正规化** | 1930.5—1931.11 | 军团制、方面军制建立 | 红一/三军团、红一/四方面军、红二军团 |
| **三、鼎盛与反"围剿"** | 1931.11—1934.10 | 中华苏维埃成立，红军总部设立 | 红五、七、八、九、十军团；红二十五军；红六军团 |
| **四、长征** | 1934.10—1936.10 | 四路红军战略转移 | 陕甘支队、红十五军团、三大主力会师、西路军 |
| **五、改编** | 1936.10—1937.10 | 改编为八路军、新四军 | 115 / 120 / 129 师；新四军 |

## 三、创建期（1927.8—1930.5）

### 3.1 三大起义与"工农革命军"

| 时间 | 事件 | 部队去向 |
|---|---|---|
| 1927.8.1 | 南昌起义 | 沿用「国民革命军第二方面军」番号，贺龙兼总指挥、叶挺兼前敌总指挥；南下失败后，朱德、陈毅率余部转战湘南 |
| 1927.9 | 湘赣边界秋收起义 | 工农革命军第一军第一师（毛泽东），进军井冈山 |
| 1927.12 | 广州起义 | 工农革命军第四军（叶挺、张太雷），失败后部分转海陆丰 |

**定名节点**：1928 年 5 月 25 日，中共中央《军事工作大纲》后，各地工农革命军陆续改称「红军」。1931 年后全国统一称「中国工农红军」。

### 3.2 井冈山：第一支红四军

| 项目 | 内容 |
|---|---|
| 成立 | 1928.4 朱德、毛泽东两部井冈山会师 → 工农革命军第四军；1928.5.25 改称**中国工农红军第四军** |
| 主官 | 军长朱德，党代表毛泽东，参谋长王尔琢 |
| 意义 | 红军史上第一支红四军，也是第一支打出"红军"旗帜的部队 |
| 去向 | 1930.6.19 与红六军、红十二军在福建汀州合编为红一军团 |

### 3.3 平江起义与红五军

| 项目 | 内容 |
|---|---|
| 成立 | 1928.7 平江起义 → 红五军（彭德怀、滕代远） |
| 去向 | 1928.12 上井冈山与红四军会合；1930.6 与红八军合编为红三军团 |

## 四、正规化期（1930.5—1931.11）

**制度背景**：1930 年 5 月全国红军代表会议决定各地红军集中组成军团；1930 年 4 月中央军委《军事工作计划大纲》决定成立军团以上统一指挥机关。

### 4.1 红一军团

| 项目 | 内容 |
|---|---|
| 成立 | 1930.6.19，福建汀州（长汀） |
| 由谁合并 | 红四军 + 红六军（1930.7 改称红三军）+ 红十二军 |
| 主官 | 总指挥朱德，政治委员毛泽东 |
| 去向 | 1930.8.23 与红三军团合编为红一方面军 |

### 4.2 红三军团

| 项目 | 内容 |
|---|---|
| 成立 | 1930.6，湖北大冶 |
| 由谁合并 | 红五军 + 红八军 |
| 主官 | 总指挥彭德怀，政治委员滕代远 |
| 去向 | 1930.8.23 与红一军团合编为红一方面军 |

### 4.3 红一方面军（中央红军）

| 项目 | 内容 |
|---|---|
| 成立 | **1930.8.23**，湖南浏阳永和 |
| 由谁合并 | 红一军团 + 红三军团 |
| 主官 | 总司令朱德，总政治委员毛泽东，总前委书记毛泽东 |
| 番号变迁 | 1931.11.25 改称**中央红军**；1932.6 恢复红一方面军；1934.1 再称中央红军；1935.6 恢复；1935.9 主力编为陕甘支队；1935.11 恢复 |
| 兵力峰值 | 约 8 万—10 万；1934.10 长征出发约 8.6 万 |
| 最终去向 | 1937.8 改编为八路军**第 115 师** |

**下辖军团一览**

| 军团 | 成立 | 主官 | 备注 |
|---|---|---|---|
| 红一军团 | 1930.6 | 朱德 / 毛泽东 | 红四军、红三军、红十二军 |
| 红三军团 | 1930.6 | 彭德怀 / 滕代远 | 红五军、红八军 |
| 红五军团 | 1931.12 | 季振同、赵博生、董振堂 | 宁都起义的国民党第 26 路军改编 |
| 红七军团 | 1933.7 | 寻淮洲 / 萧劲光 | 1934.7 组成北上抗日先遣队，11 月与红十军合编红十军团 |
| 红八军团 | 1934.9 | 周昆 / 黄苏 | 长征中损失惨重，1934.12 撤销 |
| 红九军团 | 1933.10 | 罗炳辉 / 蔡树藩 | 1935.7 改称红三十二军 |

### 4.4 红二军团（湘鄂西线）

| 项目 | 内容 |
|---|---|
| 前身 | 1928.6 贺龙在湘鄂西成立工农革命军第四军（第二支"红四军"）；1929 春改称红四军 |
| 成立 | **1930.7.4**，湖北公安 |
| 由谁合并 | 红四军（贺龙）+ 红六军（周逸群、段德昌） |
| 主官 | 总指挥贺龙，政治委员周逸群 |
| 番号变迁 | 1931.3 改编为**红三军**；1934.10 木黄会师后恢复红二军团番号 |
| 去向 | 1936.7 与红六军团、红三十二军合编为红二方面军 |

### 4.5 红四方面军（鄂豫皖线）

| 项目 | 内容 |
|---|---|
| 最早源头 | 1927.11 黄麻起义 → 鄂东军 → 红十一军（1930）→ 红一军（1930，许继慎） |
| 关键合并① | **1931.1** 红一军 + 红十五军 → **红四军**（军长旷继勋，后徐向前；政委余笃三，后曾中生、陈昌浩） |
| 成立 | **1931.11.7**，湖北黄安（今红安）七里坪 |
| 由谁合并 | 红四军 + 红二十五军 |
| 主官 | 总指挥徐向前，政治委员陈昌浩 |
| 兵力峰值 | 约 8 万 |
| 下辖军 | 红四、红九、红三十、红三十一、红三十三军 |
| 最终去向 | 1937.8 改编为八路军**第 129 师**；一部（红五、九、三十军）1936.10 另组西路军 |

## 五、鼎盛与反"围剿"期（1931.11—1934.10）

### 5.1 红军总部与统一指挥

- 1931.11 中华苏维埃共和国临时中央政府在瑞金成立。
- 1933.5 临时中央政府决定组织**中国工农红军总部**：朱德任总司令，周恩来任总政治委员。
- 此期红一方面军总部曾多次撤销/恢复，部队由中革军委直接指挥。

### 5.2 红六军团

| 项目 | 内容 |
|---|---|
| 成立 | 1933.6 |
| 主官 | 军团长萧克，政治委员王震 |
| 活动 | 湘赣根据地 |
| 去向 | 1934.8 西征；1934.10 与红三军在贵州印江木黄会师；1936.7 编入红二方面军 |

### 5.3 红二十五军

| 项目 | 内容 |
|---|---|
| 成立 | **1931.10.25**，安徽六安麻埠（军长旷继勋，政委王平章） |
| 重建 | 1932.11.30 重建（徐海东等） |
| 长征 | 1934.11.16 从河南罗山何家冲出发，称"北上抗日第二先遣队" |
| 到陕北 | 1935.9 到达陕北永坪 |
| 合并 | **1935.9.18** 与红二十六、二十七军合编为**红十五军团**，红二十五军改编为第七十五师 |
| 特殊地位 | 四支参加长征的红军之一，且最先到达陕北 |

### 5.4 红十军团（北上抗日先遣队）

| 项目 | 内容 |
|---|---|
| 成立 | 1934.11，红七军团 + 红十军 |
| 主官 | 方志敏、刘畴西 |
| 结局 | 1935.1 怀玉山失败，方志敏被俘就义 |

### 6.2 红一方面军的"分—合"细节（最容易画错的一段）

```
红一方面军(1934.10 长征出发)
  ├─ 红一、三、五、八、九军团 + 第一、二野战纵队
  ├─ 1935.6 与红四方面军会师 → 恢复红一方面军番号
  │    军团改军：红一、三、五军团 → 红一、三、五军；红九军团 → 红三十二军
  ├─ 1935.8 混编左、右两路军（红五、三十二军编入左路军）
  ├─ 1935.9 中央纵队 + 红一、三军 → 中国工农红军陕甘支队（北上）
  └─ 1935.11 恢复红一方面军番号
       红一、三军合编为红一军团；红十五军团编入红一方面军序列
```

## 七、改编期（1936.10—1937.10）

### 7.1 改编为八路军

| 项目 | 内容 |
|---|---|
| 谈判 | 1937.2 起国共谈判；1937.8.22 国民政府正式宣布改编 |
| 命令 | 1937.8.25 中共中央军委命令：红一、二、四方面军和陕北红军改编为**国民革命军第八路军** |
| 主官 | 总指挥朱德，副总指挥彭德怀，参谋长叶剑英，政治部主任任弼时，副参谋长左权，政治部副主任邓小平 |
| 兵力 | 全军约 4.6 万人 |
| 番号变更 | 1937.9.11 改称**国民革命军第 18 集团军**（习惯仍称八路军） |

## 十、存疑与待核

1. **红二方面军成立日期**：一说 1936.7.2（中国军网），一说 7.5（另有资料）。本报告取「1936 年 7 月」，建模时用 1936.5 中间值或标注两说。
2. **红二十五军成立日期**：常见 1931.10.25，也有资料只写 1931.10。
3. **兵力数字**：各来源差异较大（中央红军长征出发 8.6 万 vs 8.7 万），建议统一用「约」并在卡片注明。
4. **红八军团、红九军团**的撤销/改称时间点在部分资料中不一致（红八军团 1934.12 撤销；红九军团 1935.7 改红三十二军）。
5. **红十军团**是否纳入主图：它属北上抗日先遣队，与主力长征路线不同，建议作为独立小专题。
6. **陕北红军三个军的番号细节**（红二十六、二十七、二十八、二十九、三十军）在改编时的具体分配，需再核地方志。
