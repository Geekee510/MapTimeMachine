# 中国近代史数据层规范（1840–1950）

> 本目录只放**纯数据**，不含任何渲染逻辑。第四幅图（中国近代史）与将来的编辑器/导入功能共用。

## 为什么单独立一层

古代史的经验：数据分散在渲染代码里，改一个年份要翻三个文件，且容易两处漂移。
近代史信息量是古代的 3–4 倍（事件、条约、口岸、租界、铁路、割据势力），
所以数据必须先独立成层，渲染只做投影。

## 文件

| 文件 | 内容 | 关键消费方 |
|---|---|---|
| `places.js` | 地名 → 经纬度底表（一处定义，全库引用） | 全部 |
| `factions.js` | 政治实体（清 / 民国 / 各系军阀 / 伪政权 / 苏区 / 根据地 / 解放区）+ 控制区分段 | 疆域图层 |
| `events.js` | 大事记（分组、起止、一句话、长文） | 图钉、年表、卡片 |
| `wars.js` | 战争动画（沿用 `chinaHist/wars.js` 的紧凑行 schema） | 战争回放 |
| `treaties.js` | 条约、通商口岸、租界、租借地、势力范围 | 专题图层 |
| `railways.js` | 近代铁路干线（站点串，绘制时 Chaikin 平滑） | 铁路图层 |
| `redarmy.js` | 红军编制沿革（实体 + 合并/改编关系） | 行军动画、沿革树 |
| `narrative.js` | 阶段综述（5 篇）+ 专题长文（抗战、长征等） | 侧栏、专题页 |
| `index.js` | 汇总导出 + 常用查询函数 | 全部 |

## 通用约定

- **坐标一律 `[lng, lat]`**，现代经纬度，坐标系 WGS84。精度到小数点后 2 位即可（约 1km），
  这是"示意位置"而非考古定点，与古代史 `wars.js` 保持一致。
- **时间**：统一写 `年.月`，月份两位数（`1937.07` = 1937 年 7 月，`1949.10` = 1949 年 10 月，
  `1937` = 该年年初）。**绝对不要**混用"小数年"（`0.5` 表示年中）——两者混用会让
  `1937.10` 被当成 1 月、排序全错（本项目已踩过：数据里曾同时存在两种写法，156 处需重写）。
  需要比较时用 `tkey(t)`（→ `YYYYMM` 整数），**不要直接比数值**：`1937.1` 与 `1937.10`
  在 JS 里数值相等。
  显示用 `timeLabel(t)`（→ "1937 年 7 月"）。
- **不存在的时间不要写 0 或 null**，用 `null` 表示"未知/不适用"。
- **配色显式给出 `[r,g,b]`**，不要靠索引猜色（古代史踩过这个坑）。
- 一切"待核"内容写在 `note` 里并在文中标明 `待核`，不要静默猜测。

## polity / seg 模型（与古代史完全一致）

```js
{
  id: 'beiyang:zhili',
  name: '直系',
  type: 'parallel' | 'central',   // central = 法统上的中央政权
  color: [r, g, b],
  start, end,
  parent: 'beiyang',              // 可选：归入某大框架（用于分组/图例）
  segs: [
    {
      start, end,
      provinces: ['河北', '湖北'],  // 中文关键词，运行时 resolveAdcodes → 省界并集
      patches: [[[lng,lat], ...]],  // 超出现代省界的部分（租借地、境外）
      note: '控制强度：名义/实际',
    },
  ],
}
```

**为什么用省份关键词而不是直接存几何**：与 `territoryGen` 的 dissolve 管线一致，
几何只在一处生成；同时避免把 26MB 边界数据再抄一份。

**近代的特殊性**：同一块地在同一时间可能"名义属 A、实际属 B"。
用 `segs[].note` 标注控制性质（`名义` / `实际` / `争夺`），渲染时用不同透明度/描边表达，
不要为了简化而抹平——这正是近代史地图最有信息量的地方。

## 事件 schema

```js
{
  id: 'marco-polo',
  name: '七七事变',
  group: '抗战',            // 晚清 | 军阀 | 红军 | 抗战 | 解放
  start: 1937.5, end: 1937.62,
  place: '北平宛平', placeId: 'beijing',
  loc: [116.22, 39.85],     // 可省略，默认取 placeId 坐标
  belligerents: ['中国', '日本'],   // 可选
  summary: '一句话（≤40字），图钉 hover 显示',
  article: ['段1', '段2', ...],     // 卡片长文，2–5 段
  tags: ['导火索', '全面抗战'],
  weight: 3,                      // 1–3，地图上是否放大显示
}
```

## 校验

`node scripts/check-modern-data.mjs` 会检查：id 唯一、坐标范围内、时间区间合法
（start ≤ end、落在 1840–1950）、`placeId` 都能在 `places.js` 找到、颜色合法。
